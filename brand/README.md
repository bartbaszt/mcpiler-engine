# MCPiler brand assets

MCPiler Engine uses the shared **MCPiler 06F — M-Gate + connected layers** identity.

These files are repository-level copies/derivatives of the final MCPiler v1.0 brand geometry so the Engine repository remains visually self-contained.

## Assets

- `logo-horizontal.svg` — preferred portable horizontal MCPiler lockup.
- `logo-mark.svg` — full 06F mark for normal sizes.
- `logo-mark-small.svg` — sanctioned simplified mark for very small sizes.
- `favicon.svg` — small-size icon on the MCPiler neutral surface.
- `social-card.svg` — Engine-specific 1200×630 social/repository card derived from the canonical MCPiler social-card composition.

## Usage

- Spell the brand **MCPiler**.
- Keep **Engine** as a product descriptor; do not alter the MCPiler wordmark to fuse the descriptor into it.
- Keep the logo monochrome. The canonical ink is `#111315`; the neutral surface is `#FAFAF8`.
- Do not stretch, rotate, recolor individual layers, add gradients/glow, remove arbitrary nodes, or merge the mark with MCP/OpenAPI marks.
- Use the full mark at 24 px and above; use the small mark below that size.
- Preserve clear space around the mark and lockup.

Primary brand line: **Compile APIs into reliable MCP tools.**
